# 易經筆記本 - 兼備文字編輯功能（做筆記）和簡易占卜功能的易經學習工具

子曰：「書不盡言，言不盡意。」

這就是這個程式與其他易經相關的APP和開源程式不同之處的來源。

正因言不盡意，所以要用於實際生活中加以體會，其過程中領悟到的可以記筆記。筆記最好以自己能明白的方式表達，畢竟別人寫的再怎麼好，如果不是你的經歷可以體會到的，對於你來說這些文字完全是另外的味（不同於原作者的本意）。

筆記本有許多可以自訂的功能，插入圖片，預設文字內容包含易經9翼的內容（無《繫辭傳》），下載後無需上網。

這個程式雖是主打像一本方便查詢的筆記本，但是仍加上了占卜功能，作為易經實踐的一部分，只不過只有最基礎的占法，至於什麼結合六神之類的後人發明的占法以後考慮。

以前我只會C#和Matlab的程式碼，這是我的第一個JS/CSS程式，難免有問題，歡迎指正。程式碼基本是Claude Code寫的，時間都花在設計互動邏輯，不斷微調視覺效果上。（如果你看到易經相關的應用是這樣配土黃色的，基本是AI的餿主意，因為我的就是基於AI推薦的顏色微調的。）還有這個程式只在macOS和iOS（用手機版Edge瀏覽器）上測試過，如果有在不同系統使用的只管給反饋，我將不勝感激。

## 程式介紹 - 基礎

### 下載

直接可用的版本，裡面有提前加入的繁體中文預設內建內容文字，下載下來然後點擊即可使用： [ic_tc.html](ic_tc.html)

圖片都在[assets](assets)資料夾裡，需要下載[assets](assets)資料夾到和程式同一個本地位置裡才可以讀取。

內容文字來源（《周易》原文及十翼均為公有領域）：
- 繁體中文正文：[eee-learning.com](https://www.eee-learning.com/)
- 《象》：[zh.wikisource.org](https://zh.wikisource.org)

如果不怕麻煩，可下載文字空白的原版，只有200多kB（需要手動匯入文字資料，要看 程式介紹 - 自訂 的內容）：[ic.html](ic.html)

程式碼裡唯一不同只是這幾個參數：

const _EMBEDDED_CONFIG

const _EMBEDDED_HEX

const _EMBEDDED_SAVES

const DEFAULT_LANG

### 卦的資訊查詢
卦的按鈕：陰陽符號，還有這些數字都是按鈕，按了就會調取不同卦的資訊。

爻變按鈕：按了之後，以上的按鈕就會出現多兩種形態，陽變陰，和陰變陽，數字由0和1，變成6789，占卜的都知道6789是什麼意思吧。在6789狀態時，會到處看到 \ \ \ \ 的特效。

![](readmeAssets/tc_binary.png)
![](readmeAssets/tc_6789.png)

底下的頁面選擇按鈕：4個雙重邊框的，其中第四個是「卦象」，顯示變爻前後，只有在6789模式才可以打開。

![](readmeAssets/tc_guaxiang.png)

### 占卜
點擊「筮卜」按鈕，先輸入命名，然後按6次即可完成，系統自動展示產生的卦並有發光特效。同時自動儲存，以後可點擊🔍載入。查看概率請看 程式介紹 - 自訂。

![](readmeAssets/tc_shiboName.png)
![](readmeAssets/tc_shiboProgress.png)
![](readmeAssets/saves.png)
![](readmeAssets/savesDetail.png)

### 文字編輯
點擊右上角的📝按鈕，按了就可以編輯文字了，記得按右欄下面的「儲存」鍵。

文字資料會保留在瀏覽器裡，以Local Storage的形式。刪除瀏覽器資料會刪除全部文字。永久儲存資料請看 程式介紹 - 自訂。

![](readmeAssets/tc_textEdit.png)

可以有不同樣式的字體，和圖片。參考坤為地的「圖占」一欄的文字內容：

![](readmeAssets/tc_text.png)

### 手機使用
這個程式手機也可以用，就是麻煩了點。直屏時左欄和右欄擠不下，就靠中間的按鈕來回切換。

iOS的預設瀏覽器Safari不給打開本地的html檔案，所以要下載Edge，然後在點這個html檔案然後點擊分享，找到Edge的選項然後選擇用Edge打開。

### 語言選擇
左上角的🌐可更改語言，但是只會改系統語言（部分按鈕的字和系統訊息），不會改正文的字。要更改正文請看下面。

### 文字匯入/匯出
按左上角的📄，你會看到：

![](readmeAssets/tc_import.png)

其中：
text.md 是屬於正文內容，筆記的部分。

config.json 是自訂設定，可以在🛠️裡查看

saves.json 是儲存的卦象，每條都是一個6位數字，在下面的🔍查看

載入後會顯示檔案名稱和時間。這些顯示會持續到程式裡的文字被透過📝🛠️💾🔍修改為止。

匯出：下方有匯出鍵，下載下來之後，瀏覽器資料清空或者換裝置都無妨，只要匯入這些檔案即可。

### 占卜概率修改

占卜按鈕旁有⚙️按鈕，點擊之後可以查看當前概率，點擊預設還可以選擇不同的概率。預設是1:3:3:1，模擬三銅錢，可以選擇易經《繫辭傳》描述的揲蓍法，概率1:5:7:3。甚至可以自創概率預設，在🛠️創建。

![](readmeAssets/tc_shiboInfo.png)
![](readmeAssets/tc_shiboPresets.png)

### 自訂設定

上下卦的顏色不喜歡？上下卦的背景小字要換掉？頁面按鈕的名稱想修改？甚至64卦的卦名不合你意？全在🛠️裡。

![](readmeAssets/tc_config.png)

### 查看錯卦，綜卦，交卦，互卦

爻變沒啟用時，介面右上方有個「本卦」按鈕，按一次就切換到錯卦的資訊，再按再切換，在本卦，錯卦，綜卦，交卦，互卦之間切換
